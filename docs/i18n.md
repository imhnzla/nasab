# Internationalisation (i18n) & RTL

## Supported Locales

| Locale | Language | Direction | Status |
|--------|----------|-----------|--------|
| `ar` | Arabic | RTL | Default, Phase 0 |
| `en` | English | LTR | Phase 0 |
| `ur` | Urdu | RTL | Phase 7 (planned) |
| `fa` | Persian | RTL | Phase 7 (planned) |

## Routing

All routes are locale-prefixed:
```
nasab.org/ar/tree     → Arabic tree
nasab.org/en/tree     → English tree
nasab.org/            → redirects to /ar (default)
```

Locale detection order:
1. URL prefix (explicit)
2. `NEXT_LOCALE` cookie (returning user preference)
3. `Accept-Language` HTTP header
4. Default: `ar`

## File Structure

```
messages/
  ar.json    # Arabic (canonical — write this first)
  en.json    # English (mirror every key)
app/[locale]/
  layout.tsx # Sets <html lang dir>
lib/i18n/
  routing.ts    # next-intl v4 defineRouting (locales, defaultLocale)
  navigation.ts # next-intl v4 createNavigation (Link, redirect, useRouter, usePathname)
  request.ts    # next-intl v4 getRequestConfig (server-side locale + messages)
  config.ts     # re-exports routing for backwards compat
  hijri.ts      # Hijri ↔ Gregorian conversion
  arabic.ts     # Arabic text utilities
```

## Translation Key Conventions

```json
{
  "nav.home": "الرئيسية",
  "nav.tree": "شجرة النسب",
  "nav.submit": "أضف نسبك",
  "person.generation": "الجيل {number}",
  "person.born": "وُلد: {date}",
  "submission.status.pending": "قيد الانتظار",
  "submission.status.under_review": "قيد المراجعة",
  "submission.status.approved": "مقبول",
  "submission.status.rejected": "مرفوض"
}
```

Rules:
- Write Arabic key first, always
- Use ICU message format for variables: `{variable}`
- Every key in `ar.json` must exist in `en.json` and vice versa

## RTL in Tailwind

Tailwind CSS v4 has **built-in** RTL support — no plugin needed. Use logical properties:

```tsx
// ✅ Correct — direction-aware
<div className="ms-4 me-2 ps-3 rtl:text-right ltr:text-left">

// ❌ Wrong — fixed direction
<div className="ml-4 mr-2 pl-3 text-left">
```

Directional icons must be mirrored:
```tsx
<ChevronRight className="rtl:rotate-180 transition-transform" />
```

The `<html>` element sets direction from the active locale:
```tsx
// app/[locale]/layout.tsx
<html lang={locale} dir={locale === 'ar' || locale === 'ur' || locale === 'fa' ? 'rtl' : 'ltr'}>
```

## Date Formatting

All dates for historical figures show Hijri and Gregorian together:
```
١٢ ربيع الأول ٥٧٠ هـ / ٥٧٠ م
12 Rabi al-Awwal 570 AH / 570 CE
```

Arabic interface uses Arabic-Indic numerals (٠١٢٣٤٥٦٧٨٩) for Hijri dates.
English interface uses Western numerals.

## Arabic Text Utilities (`lib/i18n/arabic.ts`)

```ts
normaliseArabic(text: string): string
// Normalises Alef variants (أ إ آ ا → ا), removes tatweel (ـ)

stripDiacritics(text: string): string
// Removes harakat (fatḥa, kasra, ḍamma, etc.) for fuzzy search

transliterate(text: string): string
// Arabic → IJMES Latin transliteration for English display
```

Search always strips diacritics from both query and stored names before matching.
